## 什么是ADR

ADR（Architecture Decision Record）用于记录项目关键架构决策的背景、方案与影响。每个ADR对应一个具体的架构决策，具有独立的编号和生命周期。

---

## ADR生命周期

```
提议中 → 已接受 → [已废弃/已取代]
   ↑        ↓
  讨论    实施中
```

| 状态 | 说明 |
|------|------|
| 提议中 | 正在讨论，尚未最终决定 |
| 已接受 | 已批准，正在实施或已实施 |
| 已废弃 | 决策不再有效，无替代方案 |
| 已取代 | 被新的ADR取代，须引用新ADR编号 |

## 创建新ADR

1. 复制 `template.md` 为新的ADR文件
2. 使用下一个可用编号（当前最大编号 + 1）
3. 命名格式：`XXXX-title-kebab-case.md`
4. 填写所有章节
5. 更新本索引
6. 提交PR
